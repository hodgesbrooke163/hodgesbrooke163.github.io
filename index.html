Safety · 现场提示

黟县山区与旅游道路救援现场提示

黟县多山路、弯道、临水临崖路段，S218 / G530 旅游旺季车流集中。等待救援时先确保人身安全，再处理车辆。

高速上先撤离

车辆能移动的靠应急车道，打开双闪，人员在护栏外等待。高速拖车、吊车按安徽现行政策免收，拨打 400-808-2010 说明所在高速名称、方向和最近出口 / 服务区。

山区弯道设警示

在 G530、S479、黟七线等弯道、窄路停车，先在来车方向足够距离放置三角警示牌。夜间或雨雾天加大警示距离，人员撤到路侧安全处。

说清“镇 / 村 / 景区 / 路号”

黟县村道名称相近，位置描述尽量精确到“乡镇 + 行政村 + 景区停车场 / 桥头 / 路口 + 行驶方向”。可同步发送手机定位，缩短派车时间。

搭电、补胎、开锁分别多少钱？
